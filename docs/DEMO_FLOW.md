# Review Demo Flow

1. Show GitHub repository and branch strategy.
2. Explain Presentation/Application/Database tiers.
3. Start Docker Compose.
4. Open React frontend.
5. Register/login.
6. Add food to cart.
7. Place order.
8. Show order history.
9. Cancel pending order.
10. Login as admin.
11. Add/delete food.
12. Show Docker containers/logs.
13. Explain Jenkinsfile stages.
14. Explain ECR -> ECS/Fargate -> ALB -> RDS.
15. Demonstrate a troubleshooting command.
16. Stop required resources before review.
